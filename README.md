# Overview

This Repo serves as the frontend client for "Nashville Rides and Tours", a capstone project for NSS.

This project uses the Nashville-Tours API for the backend which can be accessed at: https://github.com/jamesfreeman114/Nashville-Tours-API


## Getting Started 

- [] Clone this repository onto your machine
- [] In the project's directory on your terminal run `npm install` to install dependencies (Tailwind, etc.)
- [] After you have the API server running then run `npm run dev` to launch the client
